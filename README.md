# BetBattleBot - Telegram бот для ставок на турніри

Telegram бот для внутрішніх ставок співробітників на результати турнірів по Dota 2 та Counter-Strike 2 з адміністративною панеллю.

## 🎯 Можливості

### Для користувачів:
- 🏆 Ставки на переможця турніру (1 місце) - 30 балів виграш
- 🥈 Ставки на 2 місце - 10 балів виграш  
- 🥉 Ставки на 3 місце - 10 балів виграш
- ⭐ Ставки на MVP гравця - 50 балів виграш
- 📊 Перегляд особистої статистики
- 🏆 ТОП вболівальників
- 📈 Результати турніру

### Для адміністраторів:
- 👥 Управління користувачами
- 🏆 Управління командами  
- 📊 Перегляд всіх ставок
- ⚙️ Налаштування турніру
- 📤 Завантаження даних через CSV
- 🧮 Автоматичний розрахунок виграшів

## 🚀 Швидкий старт

### Через Docker (рекомендовано)

1. Клонуйте репозиторій:
```bash
git clone <repository-url>
cd betbattlebot
```

2. Скопіюйте файл налаштувань:
```bash
cp .env.example .env
```

3. Відредагуйте `.env` файл з вашими налаштуваннями

4. Запустіть через Docker Compose:
```bash
docker-compose up -d
```

5. Відкрийте адмінку: http://localhost:3000

### Ручна установка

1. Встановіть залежності:
```bash
npm install
```

2. Налаштуйте базу даних PostgreSQL

3. Скопіюйте та налаштуйте `.env`:
```bash
cp .env.example .env
```

4. Запустіть у режимі розробки:
```bash
npm run dev
```

## 🛠️ Технології

- **Backend**: Node.js, Express.js
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL
- **Bot**: node-telegram-bot-api
- **Контейнеризація**: Docker, Docker Compose
- **Тестування**: Jest, Supertest

## 🗄️ База даних

### Основні таблиці:

- **users** - Користувачі бота
- **teams** - Команди турніру  
- **bets** - Ставки користувачів
- **tournament_results** - Результати турніру

## ⚙️ Конфігурація

### Змінні середовища (.env):

```bash
# База даних
DB_HOST=localhost
DB_PORT=5432
DB_NAME=betbattlebot
DB_USER=postgres
DB_PASSWORD=your_password

# Telegram бот
BOT_TOKEN=your_bot_token

# Сервер
PORT=3000
NODE_ENV=production
```
